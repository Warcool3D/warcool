Privacy Policy

Warcool Content Manager
Last updated: September 28, 2026

This Privacy Policy describes how Warcool Content Manager, an internal tool operated by Warcool, accesses and uses information obtained through the Pinterest API.

Warcool Content Manager is intended for Warcool's own internal use. It is not offered as a public service and is not designed to access or manage Pinterest content belonging to unrelated third parties.

Information the application may access

After authorization through Pinterest OAuth, the application may access information associated with the authenticated Warcool Pinterest business account, including:

  • basic Pinterest account information;
  • Pins created or managed by Warcool;
  • Pinterest boards belonging to the authenticated account;
  • Pin and board metadata;
  • analytics and performance data made available through the Pinterest API.

How the information is used

Information obtained through the Pinterest API is used only for Warcool's internal content-management and marketing-analysis purposes. This may include:

  • reviewing and organizing Warcool's own Pins and boards;
  • identifying Pins that link to Warcool products;
  • updating destination URLs on Warcool's own Pins;
  • adding Warcool affiliate tracking parameters to product links;
  • exporting performance information for internal analysis and reporting.

Authentication and credentials

Pinterest login credentials are not collected or stored by Warcool Content Manager. Authentication is handled through Pinterest's authorization system. API access tokens required for authorized Pinterest API access may be stored locally in a secure configuration on systems controlled by Warcool.

Data sharing and sale

Data obtained through the Pinterest API is not sold, rented, or used for third-party advertising profiles. It is not shared with unrelated third parties except when required by law or when technically necessary to operate services explicitly authorized by Warcool.

Data retention

API-derived data may be stored locally for as long as it is reasonably necessary for content management, reporting, backup, and audit purposes. Data that is no longer needed may be deleted from Warcool-controlled systems.

Revoking access

Pinterest API access can be revoked through the relevant Pinterest account or application settings. After access is revoked, Warcool Content Manager will no longer be able to make authorized Pinterest API requests using the revoked token.

Security

Warcool takes reasonable measures to protect locally stored API credentials and exported data against unauthorized access, disclosure, alteration, or destruction.

Changes to this policy

This Privacy Policy may be updated when the application's functionality or applicable platform requirements change. The date at the top of this page indicates the most recent revision.
